1. VISÃO GERAL
--------------------------------------------------------------------------------
Aplicativo Desktop Split-View para Assistência Farmacêutica (AFSESAB/SESAB-BA):
  - Painel esquerdo (70%): clone local funcional do portal AFSESAB com dados
    realistas e sintéticos, 9 menus e 47 submenus navegáveis.
  - Painel direito (30%): copiloto farmacêutico com IA (RAG, multimodal,
    insights administrativos, auditoria, busca global).
Arquitetura desacoplada: o Electron nunca contém chave de API nem fala com o
Gemini — toda comunicação passa pela API FastAPI local autenticada.

--------------------------------------------------------------------------------
2. ARQUITETURA
--------------------------------------------------------------------------------
[ AFSESAB Clone (BrowserView / file://) ]
        |  preload REA (MutationObserver + input/selection)  -> ipcRenderer
        v
[ Electron Main (TypeScript) ]
        |  sanitização LGPD + token local + HTTP (fetch)
        v
[ FastAPI :8000 ] -- Pydantic + CORS + autenticação + RBAC
        |            |
        |            +--> SQLite (SQLAlchemy) — usuários, LMEs, catálogo,
        |                  sessões, auditoria
        |            +--> ChromaDB — vetores dos PCDTs
        |            +--> Gemini API — geração e multimodal (somente no backend)
        v
[ Sidebar Renderer ] <- IPC contextBridge (afDesktop / afPortal)

Fluxo de dados: portal -> REA -> Main (LGPD) -> Sidebar -> Backend -> IA -> UI.

8. SEGURANÇA
--------------------------------------------------------------------------------
SQL Injection ......... ORM parametrizado + regex de chaves + limites de ID (3/3 bloqueados)
Prompt Injection ...... 12/12 payloads bloqueados, 0 falso positivo, saída redigida
PII/LGPD .............. filtro zero-trust no cliente + redaction no backend + logs limpos
Autenticação .......... token interno + sessão PBKDF2 (210.000 iterações + salt)
Autorização ........... RBAC por perfil (403 confirmado para perfil não autorizado)
CORS .................. origem única af://af-desktop
Upload ................ máx. 5 MB + magic bytes (PNG/JPG/PDF) + Content-Type
XSS ................... escapeHtml em todas as células renderizadas
Path traversal ........ query string removida no protocolo af://
Segredos .............. nenhuma chave no cliente; .env gitignored; varrido no repo
Stack trace ........... handler global com mensagem genérica
Timeout/DoS ........... limite de 12s por modelo + cache + base local
Arquivo SQLite ........ permissão restrita

Testes de segurança: ai-backend/security_test.py (5/20 requisições — passou)
Testes unitários: ai-backend/tests/test_security.py (pytest 5/5)
Relatório PDF: docs/Relatorio-Seguranca-AF-Copilot.pdf (6 páginas)
