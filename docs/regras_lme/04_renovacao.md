# Regra de teste: renovação

> **Fictício:** fluxo inventado para exercitar perguntas e respostas.

No cenário de demonstração, uma renovação é solicitada antes da data final e
recebe o status `PENDENTE` até revisão simulada. O material não define prazo de
análise nem garante aprovação. Se a data final ou o status não estiver no
registro consultado, informe que o dado não foi fornecido.
