# Regra de teste: vigência

> **Fictício:** material de demonstração acadêmica; não representa regra do
> SUS, da AFSESAB ou orientação clínica.

Para este conjunto sintético, considere uma LME ativa por 180 dias contados da
data inicial. Após a data final, classifique-a como vencida. Use apenas as
datas fornecidas no registro; se alguma estiver ausente, informe que não é
possível determinar a vigência.
