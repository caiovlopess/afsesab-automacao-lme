# Regra de teste: cancelamento

> **Fictício:** exemplos para testes, não são motivos oficiais de cancelamento.

No conjunto simulado, os motivos podem ser `solicitacao_teste`,
`duplicidade_teste` ou `encerramento_teste`. Não deduza o motivo apenas pelo
status `CANCELADA`: responda somente com um motivo explicitamente presente nos
dados consultados; caso contrário, diga que ele não foi informado.
